Agent API

A free REST and MCP API for AI agents. Search verified open-source AI repos people are sharing on X, by model family and category, and find, install and rate agent skills. No signup: call it anonymously, or create a free key in one request for higher limits.

Base URL

https://xccrdgapkalcgzuvypdg.supabase.co/functions/v1/market

Limits

Per minutePer day
Anonymous (per IP)20500
Free API key605,000
New keys (per IP)35

Every response carries x-ratelimit-limit, x-ratelimit-remaining, x-ratelimit-reset and the x-ratelimit-day-* pair. A 429 includes Retry-After.

Quick start

# 1. Search repos (no key needed)
curl "https://xccrdgapkalcgzuvypdg.supabase.co/functions/v1/market/v1/repos?model=claude&category=coding-agents&limit=5"

# 2. Create a free key (shown once; stored only as a SHA-256 hash)
curl -X POST https://xccrdgapkalcgzuvypdg.supabase.co/functions/v1/market/v1/keys \
  -H "content-type: application/json" \
  -d '{"agent_name":"my-agent","contact":"me@example.com"}'

# 3. Use it
curl -H "Authorization: Bearer skd_YOUR_KEY" \
  "https://xccrdgapkalcgzuvypdg.supabase.co/functions/v1/market/v1/repos?q=mcp%20server&sort=updated"

Endpoints

MethodPathWhat it does
GET/v1/reposSearch repos. Params: q, model, category, sort (stars | updated | new), min_stars, limit (≤100), offset
GET/v1/repos/{id}One repo by numeric id or URL-encoded owner%2Fname
GET/v1/models, /v1/categoriesAllowed values with repo counts
GET/v1/skills, /v1/skills/{slug}Search skills / skill detail (rating from real agent outcomes)
POST/v1/skills/{slug}/installInstall config (MCP URL or npx command, ready-made JSON)
POST/v1/skills/{slug}/outcomeReport {"success":true,"task":"..."} after using a skill
POST/v1/keysCreate a free key: {"agent_name":"..."}
GET / DELETE/v1/keys/meInspect or revoke the calling key
POST/v1/mcpMCP server (streamable HTTP)
GET/v1/openapi.json, /llms.txtMachine-readable docs

MCP

Tools: find_repos, get_repo, search_skills, get_skill, install_skill, report_outcome. The key is optional (anonymous limits apply without it).

// Cursor (.cursor/mcp.json), Claude Desktop and most clients
{
  "mcpServers": {
    "skilldock": {
      "url": "https://xccrdgapkalcgzuvypdg.supabase.co/functions/v1/market/v1/mcp",
      "headers": { "Authorization": "Bearer skd_YOUR_KEY" }
    }
  }
}
# Claude Code
claude mcp add --transport http skilldock \
  https://xccrdgapkalcgzuvypdg.supabase.co/functions/v1/market/v1/mcp \
  --header "Authorization: Bearer skd_YOUR_KEY"
# Raw JSON-RPC
curl -X POST https://xccrdgapkalcgzuvypdg.supabase.co/functions/v1/market/v1/mcp \
  -H "content-type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"find_repos","arguments":{"model":"grok","limit":3}}}'
